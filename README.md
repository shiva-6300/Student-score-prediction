# Student Exam Score Prediction using Machine Learning

## Project Overview

This project predicts a student's exam score based on the number of study hours using Linear Regression.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## Project Workflow

1. Create and load the dataset.
2. Check and handle missing values.
3. Separate input features and target variables.
4. Split the data into training and testing sets.
5. Train a Linear Regression model.
6. Evaluate the model using MAE and R² score.
7. Predict exam scores from user input.
8. Visualize actual scores and the regression line.

## How to Run

Install the required libraries:

```bash
pip install pandas numpy matplotlib scikit-learn
```

Run the program:

```bash
python student_score_prediction.py
```
